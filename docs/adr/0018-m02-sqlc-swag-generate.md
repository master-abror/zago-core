# ADR-0018 — M02: sqlc, swag, dan pemeriksaan `generate-check`

**Status:** Diterima · **Tanggal:** 2026-10-12 · **Konteks:** M02 T5e (docs/21, docs/16 §2, docs/19 §3)

## Konteks
T5e menyalakan dua generator yang sebelumnya hanya terpasang sebagai `tool` di `go.mod` (sqlc v1.31.1, swag v1.16.6) dan menambah
pemeriksaan "keluaran generator tidak basi". Dokumen berselisih tentang lokasi keluaran swag: docs/08 §9 menyebut `docs/swagger.json`,
sedangkan docs/16 dan docs/19 §3 menyebut `docs/api`. Selain itu `--parseDependency` pada perintah docs/16 ternyata WAJIB, bukan hiasan:
tanpanya swag gagal menemukan tipe generik (`cannot find type definition: httpx.Envelope[...]`) karena pemetaan jalur impor hanya
dibangun dari `go list -deps` berkas utama (`backend/cmd/api/main.go`, yang mengimpor paket handler secara transitif).

## Keputusan
1. **Lokasi keluaran swag = `docs/api`** (docs/16 dan docs/19 menang atas docs/08 §9). Hanya `swagger.json` (`--outputTypes json`):
   paket Go `docs.go` tidak dibutuhkan karena tidak ada Swagger UI yang disajikan, dan tanpa itu `go.mod` tidak berubah.
2. **Perintah `make generate`:** `go tool swag init -g backend/cmd/api/main.go -o docs/api --parseDependency --outputTypes json
   --tags '!kernel-dev'`. Filter `!kernel-dev` mengecualikan endpoint dev/test (`/api/v1/_kernel/echo*`, ADR-0016) dari dokumen yang
   dipublikasikan; endpoint itu tetap dianotasi (tag `kernel-dev`) dan terbukti valid dengan menjalankan swag tanpa filter. Parameter tipe
   generik sepaket ditulis tanpa kualifikasi paket (`httpx.Envelope[echoResponse]`).
3. **Bentuk envelope punya satu definisi yang diekspor** di `kernel/httpx`: `Envelope[T]`, `ErrorEnvelope`, `ErrorBody`. `Responder` menulis
   persis tipe itu dan anotasi swag merujuknya; `envelope_types_test.go` mendekode keluaran `Responder` secara ketat (field tak dikenal =
   gagal), sehingga dokumen OpenAPI tidak bisa menyimpang dari respons nyata. `health.report` menjadi `health.Report` (diekspor) untuk alasan
   yang sama; anotasi pertama adalah endpoint health, jadi dokumen yang dipublikasikan sudah tidak kosong.
4. **sqlc:** `sqlc.yaml` di akar repo; skema = `backend/migrations` (format golang-migrate; `.down.sql` diabaikan sqlc). Query pertama ada di
   `backend/internal/audit/repository` (bentuk `repository/` docs/10 §3): `ListActivitiesByRequestID` (dipakai tes ujung-ke-ujung T5f).
   Opsi: `sql_package: pgx/v5`, `emit_pointers_for_null_types` (kolom nullable = `*T`), `omit_unused_structs` (tiap paket hanya memuat model
   yang dipakai query-nya), `emit_empty_slices`; override `uuid` ke `github.com/google/uuid.UUID` (nullable: `*uuid.UUID`) dan `timestamptz`
   ke `time.Time`. Query platform (`organization_id` NULL = semua organisasi) memakai parameter nullable; pemanggil bertenant wajib
   mengisinya (docs/10 §13). Skema modul (`modules/*/migrations`) ditambahkan ke daftar `schema` saat modul pertama datang (M07).
5. **`make generate-check`** (bagian dari `make verify`, setelah `lint`): mengambil sidik jari keluaran generator yang ada (seluruh
   `docs/api` dan berkas Go bertanda "Code generated by sqlc"), menjalankan `make generate`, lalu membandingkan. Berbeda → gagal dan
   keluaran terbaru dibiarkan di disk untuk di-commit. Sengaja BUKAN `git diff --exit-code`: pendekatan itu tidak melihat berkas baru yang
   belum di-`git add` dan memberi alarm palsu di pohon kerja yang sedang dikerjakan (diff terhadap indeks). Pemeriksaan ini mendeteksi
   "sumber berubah, generator belum dijalankan"; "keluaran dibuat tetapi lupa di-commit" tetap ditangkap CI lewat pohon bersih
   (`git status --porcelain` setelah `make generate`, docs/19 §3).

## Konsekuensi
- Nama definisi swag diturunkan dari jalur impor (`backend_internal_health.Report`; tipe generik jauh lebih panjang). Dapat diterima untuk
  M02 (hanya satu definisi publik); dievaluasi ulang saat generator SDK TypeScript dipilih (M10, I-14), mis. dengan `--useStructName` atau
  `swaggertype`.
- `make generate` sekarang butuh `go list` yang berfungsi dan seluruh modul terunduh (sudah benar di mesin pengembang dan CI).
- Doc-sync (ritual akhir M02): docs/08 §9 (lokasi `docs/api/swagger.json`; envelope = `httpx.Envelope`), docs/16 §2 (flag `--outputTypes`,
  `--tags`; target `generate-check`; `verify` memuatnya), docs/19 §3 (pakai `make generate-check` + pemeriksaan berkas baru), docs/10 §3
  (contoh `audit/repository` dan opsi sqlc).
